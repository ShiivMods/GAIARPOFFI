# Moteur de jeu

Règles indépendantes de React, Next.js et du stockage. Le serveur décide des résultats. `combat/` contient les premières règles pures reprises de la maquette et le moteur de planification ; voir [COMBAT.md](../../COMBAT.md). La planification du scénario local est persistante via la couche serveur. Aucune résolution automatique complète à ce stade. RP et progression restent à développer.
